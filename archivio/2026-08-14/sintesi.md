## Repo

### [ChromeDevTools/chrome-devtools-mcp](https://github.com/ChromeDevTools/chrome-devtools-mcp)
Server MCP ufficiale che espone Chrome DevTools (debugging, network, performance) agli agenti di coding. Utile se fai debugging assistito da un agente su applicazioni web.

### [firecrawl/anydoc](https://github.com/firecrawl/anydoc)
Convertitore in Rust da Word, PowerPoint, Excel, PDF, EPUB e altri formati a Markdown pulito, con binding Node.js e Python. Utility pronta per pipeline di ingestione documenti.

### [FareedKhan-dev/kimi-k3-in-c](https://github.com/FareedKhan-dev/kimi-k3-in-c)
Fa girare l'inferenza di un modello da 2,78 trilioni di parametri (Kimi K3) su una singola CPU con 8,24 GB di RAM, in puro C99 senza BLAS ne' GPU. Mostra quanto si possa comprimere l'inferenza di modelli enormi senza hardware speciale.

### [vercel-labs/agent-browser](https://github.com/vercel-labs/agent-browser)
CLI di automazione browser pensata per agenti AI, da Vercel Labs. Alternativa leggera quando serve solo dare a un agente accesso al web, senza montare Puppeteer/Playwright.

### [microsoft/skill-recorder](https://github.com/microsoft/skill-recorder)
App desktop che registra una sessione di lavoro sullo schermo e usa GitHub Copilot CLI per ricostruirla in passi ordinati, generando una Skill riutilizzabile. Un modo diverso di catturare know-how procedurale invece di scriverlo a mano.
