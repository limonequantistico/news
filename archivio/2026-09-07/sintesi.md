## Repo

### [stablyai/orca](https://github.com/stablyai/orca)
ADE per far girare una flotta di agenti di coding in parallelo, con la propria subscription, da desktop, mobile o runtime remoto.

### [diegosouzapw/OmniRoute](https://github.com/diegosouzapw/OmniRoute)
Gateway AI open source: un solo endpoint verso 352 provider e 1200+ modelli, con fallback automatico sulla quota e compressione dei token (dichiara 15-95% di risparmio). Si integra con Claude Code, Codex, Cursor e altri.

### [crmne/fastpotify](https://github.com/crmne/fastpotify)
Client Spotify nativo in Rust per Linux, macOS e Windows: playback locale e Spotify Connect, senza Electron.

### [vinzdg/codenotch](https://github.com/vinzdg/codenotch)
App macOS che mostra sempre a bordo schermo i limiti d'uso di Claude Code, Cursor, Codex e Antigravity.

### [okf-memory/okf-agent-memory](https://github.com/okf-memory/okf-agent-memory)
Memoria persistente Git-native per agenti di coding, in Go puro: ricerca BM25 in-memory sotto i 300µs, server MCP integrato, nessun database esterno. Dichiara -80% di token usati per il contesto.
