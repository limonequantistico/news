## Repo

### [anthropics/skills](https://github.com/anthropics/skills)
Repository ufficiale Anthropic per gli Agent Skills: il riferimento canonico per chi scrive skill per Claude Code invece di affidarsi a repo di terze parti.

### [DeusData/codebase-memory-mcp](https://github.com/DeusData/codebase-memory-mcp)
Server MCP che indicizza una codebase in un knowledge graph persistente: 158 linguaggi, query sotto il millisecondo, binario statico senza dipendenze. Taglia drasticamente i token usati per navigare il codice.

### [rtk-ai/rtk](https://github.com/rtk-ai/rtk)
Proxy CLI in Rust che riduce il consumo di token del 60-90% sui comandi di sviluppo piu' comuni, binario singolo senza dipendenze.

### [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem)
Persistenza del contesto tra sessioni di agenti di coding: cattura cosa fa l'agente, lo comprime e lo reinietta nelle sessioni successive. Funziona con Claude Code, Codex, Copilot e altri.

### [multica-ai/multica](https://github.com/multica-ai/multica)
Assegna issue a Claude Code, Codex, Cursor e altri 17 coding agent come fossero membri del team, self-hostable.
