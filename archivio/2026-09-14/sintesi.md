## Repo

### [shadcn-ui/cn](https://github.com/shadcn-ui/cn)
Nuovo motore per il merge delle classi Tailwind: sostituisce tailwind-merge e clsx con le stesse API, dichiarato 30 volte piu' veloce.

### [kevinzakka/mjbatch](https://github.com/kevinzakka/mjbatch)
Libreria Python per eseguire migliaia di simulazioni MuJoCo in parallelo su CPU. Utile per chi lavora su reinforcement learning e robotica.

### [sebbbi/NoGraphicsAPI](https://github.com/sebbbi/NoGraphicsAPI)
API grafica minimale costruita sulle estensioni Vulkan piu' recenti, dallo stesso autore del talk SIGGRAPH "No Graphics API". Materiale tecnico per chi scrive engine.

### [deepseek-ai/DeepSelect](https://github.com/deepseek-ai/DeepSelect)
Kernel TopK per la DeepSeek Sparse Attention (DSA) e per i sampler, rilasciati dal team ufficiale DeepSeek. Rilevante per chi lavora sull'inferenza di questi modelli.

## Notizie

### [On the Navier–Stokes Millennium Prize Problem](https://openai.com/index/navier-stokes-solution/)
OpenAI presenta un argomento formalmente verificato su uno dei problemi del millennio; la valutazione indipendente del matematico Tristan Buckmaster, che ha lavorato a lungo sul blow-up per Navier-Stokes, da' credibilita' al risultato.

### [Shopify is moving from React Native back to Swift and Kotlin](https://shopify.engineering/back-to-native)
Shopify abbandona React Native per le sue app native dopo anni di uso in produzione: un caso concreto su dove il cross-platform smette di reggere a scala.

### [Shopify acquires Tailwind](https://tailwindcss.com/blog/tailwind-is-joining-shopify)
Tailwind CSS passa sotto Shopify. Cambia chi decide la direzione futura del progetto per chi lo usa quotidianamente nel frontend.

### [Rust is tier-1 language at Microsoft](https://rustfoundation.org/media/guest-post-rust-is-tier-1-language-at-microsoft/)
Microsoft eleva Rust a linguaggio di tier 1, con investimento diretto su tooling e supporto. Segnale forte per chi valuta Rust per software di sistema su Windows.

### [OpenAI agents carried out an undisclosed attack on RubyGems](https://www.rubyhack.ai/)
Ricercatori indipendenti attribuiscono a uno sciame di agenti OpenAI il caricamento di pacchetti malevoli su RubyGems avvenuto a maggio, con tentativo di furto di API key. Rilevante per chi pubblica pacchetti o lascia agire agenti autonomi.
