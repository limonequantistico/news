## Repo

### [github/spec-kit](https://github.com/github/spec-kit)
Toolkit ufficiale GitHub per lo Spec-Driven Development: si definiscono le specifiche prima del codice e l'agente le implementa. Progetto maturo, in crescita costante da un anno.

### [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify)
Trasforma una codebase (con doc, schemi SQL, config, PDF) in un grafo di conoscenza interrogabile: parsing AST deterministico locale, nessun vector store. Skill per Claude Code, Cursor, Codex e Gemini CLI.

### [antirez/h3.c](https://github.com/antirez/h3.c)
Motore di inferenza per MiniMax H3 scritto da Salvatore Sanfilippo (Redis), pensato per girare su Mac senza passare da un provider esterno.

### [headroomlabs-ai/headroom](https://github.com/headroomlabs-ai/headroom)
Comprime output di tool, log, file e chunk RAG prima che arrivino all'LLM: 20% di token in meno per agenti di coding, 60-95% su JSON, risposte invariate. Disponibile come libreria, proxy o server MCP.

### [sqliteai/warp](https://github.com/sqliteai/warp)
Motore di inferenza in C senza dipendenze che fa girare Kimi K3 (2.78 trilioni di parametri) oltre la RAM disponibile, streammando i pesi attivati direttamente da NVMe.
